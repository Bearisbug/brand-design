# 字体与资产交付

<a id="bd-type-001"></a>
## BD-TYPE-001 · 字体证据

- 触发：制作字标、选择字体，或交付含文字的品牌应用。
- 规则：区分原参考字体是否已识别、当前选择的真实字体、定制字形和生成字样。按语言、用途、字重/轴及文件许可筛选；每个角色不强制使用不同家族。实际使用字体必须记录官方来源、版本或 SHA、许可证与文件；仅网页预览不等于已经取得字体或分发许可。
- 产物：真实品牌名、标题、正文、数字与标点样张；按项目语言检查中文、英文、代码和 fallback。可从 [字体库](../libraries/fonts/INDEX.md)选起，未知原字体明确未知。交付字标可转轮廓，同时保留构造文件、字体选择与可编辑文字来源。
- 验证：检查实际字形覆盖、字体加载、字重、换行和小字号阅读；缺字或资源不可用时换可取得的候选并说明，不能伪造原字体。是否附字体文件依据已读取的实际许可。

<a id="bd-master-001"></a>
## BD-MASTER-001 · 可编辑母版

- 触发：制作或修改正式标志母版，或固定画布品牌物料的编辑源。
- 规则：为正式标志建立可编辑母版。将位图探索规范化重建时记录几何调整与文字重排的范围，不宣称天然无损转换。矢量母版必须由可解析的几何/路径构成；位图嵌入 SVG 不算矢量化。需要保留栅格质感的部分可作为有来源的栅格母版独立交付。含可编辑文字的固定画布 PNG 物料可使用静态 HTML/CSS 排版母版，保留实际文字及字体、图形和样式依赖，并按 [合同](validation-contract.md)登记源文件与派生 PNG；禁止将压平成品嵌进 HTML 冒充可编辑排版。产品工程入口及依赖脚本才生成正文的空壳不属于此母版类型。
- 产物：源文件、构造参数或可复现脚本、已选输入与重建说明。字标正式拼写、间距和曲线与输出一致；原文件与导出使用稳定路径和版本。
- 验证：按源类型检查并实际渲染母版；查看与选中稿、色版和组合的对应关系。HTML 排版以浏览器核对约定画布、真实文字和依赖加载，确认 PNG 来自当前排版源；文件与静态结构检查不证明这些事实。任何简化改变识别含义时应作为方向变更处理，不能藏在导出步骤中。

<a id="bd-export-001"></a>
## BD-EXPORT-001 · 交付矩阵

- 触发：导出正式品牌资产的 SVG/PNG、色版、图文组合、favicon 或应用素材。参考研究、方向比较和独立字体样张的图片按 BD-DELIVERY-001 交付阶段记录与证据。
- 规则：先按真实用途确定格式、尺寸、背景和状态，不为文件数量创建无用变体。普通色版与组合从同一母版生成；光学校正版允许几何差异，但必须标记 optical、来源和使用理由。材质版单列，不套普通色版几何等同检查。平台特定图标要求在实际接入时查官方资料。
- 产物：交付矩阵和 manifest，按 [合同](validation-contract.md)逐文件记录角色、母版、格式、尺寸、校验与变体类型。使用模板时引用当前母版、色彩与字体，不独立重画另一套标志。
- 验证：每项承诺均有实际可读文件；检查画布、边缘、尺寸和真实 Alpha。透明 PNG 不得含伪棋盘或实色底；裁切后安全区与外部排版留白分别说明。

<a id="bd-qa-001"></a>
## BD-QA-001 · 实际验证

- 触发：方向评审、字体或正式资产交付前。
- 规则：机械检查、视觉目检与行为测试分别记录。至少覆盖本次承诺的小尺寸、单色/反白、深浅底、名称拼写、字距和实际应用。网页或字体接入用实际浏览器验证；本机默认 Edge。工具或平台未取得时列出具体未测项及影响，不把文件存在或校验器通过当成视觉通过。重建、打包或清单刷新脚本自动沿用已有检查状态时，必须核对证据绑定的实际产物及关键输入指纹（例如 SHA-256）；变化、缺失或没有绑定时保留旧证据并将该项标为 `not_run`，不得自动续写 `pass`。
- 产物：实际尺寸对照图、渲染/浏览器证据、机械输出，以及失败修正记录。最小尺寸和安全区依据本品牌实际结果，禁止从其他品牌搬来固定数值。
- 验证：检查记录能指向对应版本与文件；重新导出后更新受影响证据。提供上述会沿用检查状态的脚本时，用临时副本改变一项相关资产或输入，真跑并确认旧结论会失效；不得改动正式稿来做故障验证。声明 validated 时必须限定任务、输入、版本和通过的具体范围，不概括未测风格或平台。

<a id="bd-delivery-001"></a>
## BD-DELIVERY-001 · 成品与证据

- 触发：交付一个阶段或完整基础品牌包。
- 规则：工作记录与正式资源分开，交付只覆盖约定阶段。正式资产 release 包含约定的可编辑源、导出、使用说明、来源/许可、manifest 和 QA；参考研究、方向比较或独立字体样张按对应规则交付记录与证据，不要求为此新建母版或 release。只有真实需要的条件目录才建立。第三方参考留在研究区，不混成新品牌可用资产。
- 产物：在用户项目内交付时，release 与过程稿的位置按 [BD-HANDOFF-001](handoff.md#bd-handoff-001)「落位」；用户指定位置优先。交付可浏览总览、实际使用说明和每项文件入口，来源与未测项写清。
- 验证：正式资产 release 运行合同的品牌包校验命令，人工核对 manifest 状态；其他阶段检查对应规则要求的路径、来源、实际输出与证据。有视觉产物时按 BD-QA-001 验收。本次约定阶段完成与完整品牌流程完成分别陈述，不把规则、模板或目录建立等同于完整品牌能力已验证。
