# 黑色胶囊眼极简 Bot 头像

当用户要求将已有的人物或角色转成黑色胶囊眼、圆脸、倾斜超近景的极简 Bot 头像，或明确选择本风格时使用。适合品牌角色、助手头像和社区身份图；不适用于字标、抽象符号、写实肖像或要求完整身体的角色插画。检索别名：Grok bot icon、Grokbot、胶囊眼机器人、歪头头像。

本包结合用户提供的韩文规范与网站 10 张真实示例；[逐例观察](EXAMPLES.md)区分短提示词组、完整提示词组及其与规范的差异。图片是来源网站的生成结果，不是本库的转换测试；原输入人物图未知。来源、韩文原文与整理说明见 [SOURCE.md](SOURCE.md)，生成任务使用 [PROMPTS.md](PROMPTS.md)。Grok bot icon 在本包中只是来源所用的视觉规范名称，不表示官方归属或授权。

仅选用本风格的任务适用以下局部参数。运行时、用户当前要求和上层 Skill 优先；源文中的回应方式不能覆盖运行时要求或扩张当前任务。规范说明、入库、分析、Prompt 修改只处理文字，不触发生图。

## 观察与规范的区别

十张样例共同展示黑色胶囊眼、没有嘴鼻的圆脸、腮红与大块发型。S02 的倾斜方向与用户完整规范相反，F05 可见手和较多衣装；若干示例的下巴完整入框、背景或头发带柔和明暗。它们作为来源输出如实保存，不视为全部约束通过，也不从中反推规范数值。执行仍以本包整理的用户规范为准。

## 识别与参考角色

| 维度 | 采用方法 |
| --- | --- |
| 标志类型 | 人物／角色头像，可作为品牌吉祥物的局部表现 |
| 构思 | 用原对象的大轮廓和少量识别特征保留身份，以固定眼部结构形成系列感 |
| 形状语法 | 圆润大脸、两个竖长胶囊、简化发块、小椭圆腮红 |
| 表现 | 近乎无描边的平涂二维色面，至多一层宽而弱的明暗 |
| 构图 | 正方形，左下探头、顺时针倾斜、贴边裁切，右上留深色空白 |
| 字体角色 | 图内不排文字；品牌字标须另行设计和交付 |

先查看转换对象，记录其肤色或面部表面基础色、发色、发长、分缝、卷曲度、刘海、束发方式。保持这些基础色；从耳朵、帽子、眼镜、胡须、饰物和机械部件中，选约三项以内最关键的形态特征，优先大轮廓。无头发或头发被遮住时保持原状，禁止添加原图不存在的刘海、饰物或机械件。

不复制原表情与写实骨骼；衣装和装备只留识别必需部分。若另有风格参考图，它只控制表现方法；肤色、发色、发型、饰物只能取自转换对象，禁止将风格参考人物的外貌移入结果。

## 面部与双眼

- 脸大且圆，面颊与下巴柔和连接；用宽而平滑的基础色面，避免尖下巴、棱角和写实骨架。可爱感来自比例与倾斜，不靠表情装饰。
- 不画嘴和鼻子，包括笑嘴、点状嘴、猫嘴。双颊各放一个小而淡、低饱和、与肤色协调的椭圆腮红；平涂，不加线条或闪光。眼睛与腮红周围保留空白脸面。
- 双眼恰好是两个近黑色实心胶囊。头部摆正时，长轴竖直，长度约为宽度的 2.5–3 倍；两眼等大、平行，两端圆。每个长轴均与双眼中心连线垂直。
- 胶囊本身就是眼睛，必须单色填满；不加眼球、瞳孔、虹膜、眼白、高光、渐变、睫毛、眼皮、眉毛、边框或数字 1 式钩脚。禁止横条、闭眼弧线；优先于原对象眼形和眼色。
- 核心眼镜和胡须可保留简化轮廓。眼镜不能遮住双眼；胡须不能借机画出口部或写实面部结构。

## 构图与色面

1. 一张 1:1 正方形画布只放一个角色，脸与头部外轮廓占据大部分画面。角色从画面左下探入，头部在屏幕平面顺时针倾斜约 15–20°，画面左眼略高于右眼。
2. 脸、眼、头发、附着饰物一起旋转；双眼保持完整可见。头部左缘与下缘自然超出画布，下巴接触或部分越过底边，右上保留深色背景。禁止小头像居中证件照式构图或左右对称构图。
3. 不画躯干和手；只有识别需要时，在底边留下少量脖颈或衣领。这里的贴边裁切是主动构图要求，不按整头完整入框验收。
4. 发型简化为少量大而光滑的色块，保留原发流、长度感与整体轮廓。用相邻色面区分形状，避免粗黑外描边。
5. 代表色平涂；至多一层宽而弱的阴影。若需要发丝高光，仅一两块大色面。饰物和机械件仅留轮廓与主要连接，省去螺丝、细线、线路、密集面板线和复杂花纹。
6. 全画布背景为近黑深炭灰纯色，不加入景物、花纹、圆形框、徽章边、文字、数字、Logo、水印、气泡、感叹符、闪粉、粒子、光晕或镜头光斑。避免实拍、三维渲染、油画肌理、粗糙草稿线、过度光泽、复杂明暗、碎发与堆饰。

## 参数与冲突处理

本包的 1:1、15–20° 和 2.5–3 倍来自用户提供的制作规范，不是网页图片的测量值。可依对象调整：基础色、发型大块、最多约三项关键特征、淡腮红色、弱阴影，以及在规定角度范围内的倾斜与裁切位置。不得将这些局部参数写成全库的 Logo 约束。

局部要求冲突时，依次保护：① 两个纯黑胶囊眼；② 没有嘴鼻的圆润 Bot 脸；③ 双眼完整可见的倾斜超近景；④ 原对象基础色与关键识别特征；⑤ 其他细节。刘海挡眼时，在保留发流的前提下微调长度、宽度或位置；关键饰物被完全裁掉时，小幅移动或缩放到仍可识别。调整不得创造原图没有的特征。

## 执行、修改与验收

已经选择本风格后，用户请求生成／转换，或只附一张明确的转换对象图且未提出其他问题时，按默认转换处理。无法查看对象图时请求附件；多人且未指定对象时只确认转换哪一位。不要在单纯收录或讨论规范时索要对象图。

使用当前可用的图像生成／编辑工具完成一张实际图像；接口和图片传入方式以真实工具为准。单图转换默认交付图像，省略额外说明与图内制作规格；运行时要求的文件或说明仍须满足。仅解释、分析或修改 Prompt 时用文字回答。后续局部修改只改变用户点名部分，保留其余风格参数和角色身份。

实际生成后，对照对象图检查：身份特征及基础色、眼睛数量与比例、眼内纯色、嘴鼻缺席、眼睛完整可见、左眼高右眼低、整头一致倾斜、左下裁切与右上留白、纯色背景、禁用元素。还须在实际目标头像尺寸检查两眼与核心轮廓；未指定尺寸时记录所选比较尺寸，不能据此宣称所有平台或 16px 都适用。记录真实输入、完整 Prompt、工具、输出与目检结论；未运行不得标为通过。
