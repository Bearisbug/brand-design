# Stefan Kanchev · 装饰与民艺符号 Prompt

先按 [STYLE.md](STYLE.md) 判断适用范围。以下是研究者编写的自然语言模板，未实测，非作者原始提示词。提交前替换所有字段；已有简报与用户选定方向优先。参考作者姓名只用于出处，不代替可观察的视觉描述。

## 新构思探索

```text
Create an original ornamental brand symbol for {{brand}} based on {{verified cultural context or brand-specific motif}}. Organize {{primary motif}} through {{axial symmetry, radial repetition or ordered interlace}}. Use {{repeat unit}}, {{solid-to-line balance}} and deliberate open spaces to keep the figure readable at {{target size}}. Reference images guide compositional rhythm only; do not copy a historical emblem or its culturally specific details. Begin with a flat one-color mark on {{background}} and add {{limited palette}} only after the structure is clear. Do not add dates, ethnic meanings or historical claims absent from the brief.
```

## 已选版本定向修改

仅在已有自有品牌选定稿且用户要求局部调整时使用：

```text
Use {{approved own-brand artwork}} as the authority for {{silhouette, parts, letter sequence and composition}}.
Change only {{requested variable}} to achieve {{observable improvement}}.
Keep {{accepted decisions}} unchanged.
Use {{style reference}} only for {{specific permitted shape, spacing or expression property}}.
Show the result beside the approved version at {{comparison size}}.
If the request changes the concept, create a clearly separate concept instead of labeling it a minor revision.
```

## 输出核对

- 单色下主意象和装饰组织仍清楚，不依靠做旧纹理。
- 检查中心交汇、螺旋内侧与重复单元间隙，目标尺寸下不堵塞。
- 文化含义、地域和名称来自当前简报或可靠来源，不根据外形编造寓意。
- 对照输入图与实际结果，确认“保持”要求真的生效。
- 图中文字仅为探索参考；正式名称、字体与几何在可编辑母版中核对。
- 本模板没有工具专用参数；使用时按当前可用工具的真实接口提交。
