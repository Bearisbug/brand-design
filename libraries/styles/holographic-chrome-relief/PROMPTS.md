# Martin Naumann · 虹彩金属浮雕 Prompt

先按 [STYLE.md](STYLE.md) 判断适用范围。以下是研究者编写的自然语言模板，未实测，非作者原始提示词。提交前替换所有字段；已有简报与用户选定方向优先。参考作者姓名只用于出处，不代替可观察的视觉描述。

## 新构思探索

```text
Render {{approved own-brand master}} as a holographic chrome relief for {{digital campaign or hero use}}.
The master controls the exact silhouette, holes, parts and lettering. Use {{material reference}} only for narrow chromatic reflections, metallic surface contrast, softened bevels and shallow relief.
Set {{bevel depth, lighting direction and chromatic palette}} against {{chosen background}}. Keep critical negative spaces open and readable.
Do not inherit the reference brand symbol. Do not add mechanical details, extra parts or new letters.
Provide the rendered result for comparison with the flat master at {{final display size}}. Verify geometry and actual transparency separately; the image is a presentation asset, not an editable vector master.
```

## 已选版本定向修改

仅在已有自有品牌选定稿且用户要求局部调整时使用：

```text
Use {{approved own-brand artwork}} as the authority for {{silhouette, parts, letter sequence and composition}}.
Change only {{requested variable}} to achieve {{observable improvement}}.
Keep {{accepted decisions}} unchanged.
Use {{style reference}} only for {{specific permitted shape, spacing or expression property}}.
Show the result beside the approved version at {{comparison size}}.
If the request changes the concept, create a clearly separate concept instead of labeling it a minor revision.
```

## 输出核对

- 与自有母版并排检查外轮廓、孔洞、部件数量和文字；材质不能替换识别结构。
- 所研究的高光、倒角和反射色在最终展示尺寸可辨；软光晕属于表现，不自动视为低分辨率。
- 同时保留基础平面版用于小尺寸、单色与实际产品界面。
- 图像输出按真实背景与 Alpha 状态登记，不能把背景色看似干净写成透明。
- 对照输入图与实际结果，确认“保持”要求真的生效。
- 图中文字仅为探索参考；正式名称、字体与几何在可编辑母版中核对。
- 本模板没有工具专用参数；使用时按当前可用工具的真实接口提交。
