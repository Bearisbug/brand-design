# Von Glitschka / Glitschka Studios · 插画品牌角色 Prompt

先按 [STYLE.md](STYLE.md) 判断适用范围。以下是研究者编写的自然语言模板，未实测，非作者原始提示词。提交前替换所有字段；已有简报与用户选定方向优先。参考作者姓名只用于出处，不代替可观察的视觉描述。

## 新构思探索

```text
Develop an original brand mascot for {{brand}}, intended for {{applications}}. The character is {{identity/species/object}} with {{personality and expression}}, performing {{pose or action}}. Use {{distinctive silhouette}}, {{outline character}}, flat color zones in {{palette}} and restrained shading that clarifies form. Include only the meaningful prop {{prop or none}}. References guide character hierarchy, expression and shape economy; create new anatomy, facial features, costume and pose for this brand. Present a clean isolated character and, if requested, a lockup with the exact text {{brand name}}. Check hands, eyes, mouth, object attachments and consistency at {{target size}}.
```

## 已选版本定向修改

仅在已有自有品牌选定稿且用户要求局部调整时使用：

```text
Use {{approved own-brand artwork}} as the authority for {{silhouette, parts, letter sequence and composition}}.
Change only {{requested variable}} to achieve {{observable improvement}}.
Keep {{accepted decisions}} unchanged.
Use {{style reference}} only for {{specific permitted shape, spacing or expression property}}.
Show the result beside the approved version at {{comparison size}}.
If the request changes the concept, create a clearly separate concept instead of labeling it a minor revision.
```

## 输出核对

- 遮住文字后，角色身份、主要动作和情绪仍能解释。
- 眼、嘴、手指、道具和肢体连接合理；多姿态版本保持同一角色识别。
- 单独角色与字标组合分别测试，提案和正式采用状态清楚标注。
- 对照输入图与实际结果，确认“保持”要求真的生效。
- 图中文字仅为探索参考；正式名称、字体与几何在可编辑母版中核对。
- 本模板没有工具专用参数；使用时按当前可用工具的真实接口提交。
